Fine print

Cert Jenna is a free self-signed certificate generator for local HTTPS. It creates X.509 SSL/TLS certificates for localhost and .local hostnames, with RSA-2048 keys and SHA-256 signatures—a browser-based alternative to mkcert or an openssl req command.

Private keys never leave this tab—except through the download button, obviously. Everything is generated in browser with Web Crypto, so there is no upload, no account, and no backend.

Self-signed, in browser. No servers were contacted. One throwaway root was briefly employed, then released with a small severance package.

How to use a self-signed certificate for local HTTPS

  1. Name your app. Enter the hostname your dev server uses, like my-app.local or localhost. It becomes the certificate's common name (CN) and, when it is a valid DNS name, the subject alternative name (SAN).
  2. Pick a bundle. Gen Simple gives you a throwaway server.crt and server.key. Gen Complete adds a root CA and a client certificate for mutual TLS.
  3. Trust the root, then configure your server. Import root.crt into your operating system or browser trust store, then point nginx, Caddy, Node, or Python at server.crt and server.key.

Frequently asked questions

What is a self-signed certificate?

A certificate that signs itself instead of being signed by a public certificate authority. Nothing trusts it until you import it, which is exactly what makes it useful for local development: no public CA, no DNS challenge, no waiting.

How do I use the certificate for local HTTPS?

Generate the Complete bundle, import root.crt into your operating system or browser trust store, then point your dev server at server.crt and server.key. Use Simple when you only need a throwaway server pair and can live with the browser warning.

Is Cert Jenna a mkcert alternative?

For the common case of needing a certificate for something like my-app.local, yes. The differences are that it runs entirely in the browser so there is nothing to install, and the Complete bundle also includes a client certificate for mutual TLS testing.

Where do the private keys go?

Nowhere. Keys are generated with Web Crypto inside this tab and written straight into the ZIP you download. The page makes no network requests and has no backend.

What certificate format do I get?

PEM-encoded X.509 certificates and PKCS#8 private keys, which nginx, Caddy, Node, Python and most other servers read directly. Files arrive in a ZIP named app-name-simple.zip or app-name-complete.zip.

Do I need to install anything?

No. Cert Jenna is a single static HTML page. It needs a secure context for Web Crypto, so open it over HTTPS or from localhost, then enter a name and pick a bundle.
